Requirements
    - PlatformIO
    - ESP32
    - VSCode

How to build
    - open a new window on vscode, select the firmware folder inside the tarnished-fc workspace
    - navigate to the desired .cpp file
    - click the checkmark in the bottom-right-ish of the vscode window

How to upload
    - open a new window on vscode, select the firmware folder inside the tarnished-fc workspace
    - navigate to the desired .cppm file
    - click the right facing arrow on the bottom-right-ish of the screen
